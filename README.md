# パニックDEパニック v1.1

ボールの動きや、床に作った道を眺めて楽しむ機能性玩具です。重力・跳ね返り・穴の位置による動きの違いを見ながら、自由ペンでコースを作れます。知育的な遊びを意図しています。

## 使い方

- ボール数を1～8個から選びます。
- 「消しゴム」「自由ペン」を選び、画面を指やマウスでなぞります。
- 「入口ドアを置く」「出口ドアを置く」を選んで、置きたい場所をタップします。
- 「ドアを動かす」を選ぶと、ドアをドラッグできます。
- 「床を元通り」で床を復元し、「すべて初期化」で全体を初期状態に戻します。
- 「一時停止」でアニメーションを止められます。

## GitHub Pagesへの掲載

1. ZIPを解凍します。
2. 中の `index.html` と `README.md` をGitHubリポジトリの一番上の階層にアップロードします。
3. 「Commit changes」を押します。
4. GitHub Pagesを設定済みなら、公開URLを開いて動作を確認します。

外部ライブラリや画像ファイルは使っていません。`index.html`だけで動きます。

## ご注意

これは遊び用の機能性玩具です。医療機器・治療用アプリではなく、症状の改善や安全を保証しません。知育的な動きの観察を楽しむためのものです。
